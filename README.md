# Film ve Dizi Arama Sitesi

Film ve dizi araması yapan Streamlit uygulaması.

## Kurulum
```bash
pip install streamlit requests python-dotenv
```

## Çalıştırma
```bash
streamlit run site.py
```

## Gereksinimler
- Python 3.8+
- OMDB API key

## Kullanım
1. Film adını arayın
2. Filtreler uygulayın (yıl, puan, tür)
3. Detayları görüntüleyin
